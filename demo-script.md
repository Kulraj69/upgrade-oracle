# Upgrade Oracle — 6 minute 30 second demo

Before recording: `npm run dev` with no GLM key loaded. Open http://localhost:3000 at 1440px width, set browser zoom to 100%, hide unrelated tabs and notifications. Keep a terminal ready with `npm test`, and the README open. All three demos are real recorded runs; say that explicitly. Do not display an env file or secret. Three demo calls fit within the five-per-hour limit; restart the local server before filming if needed.

| Time | On screen | Say / demonstrate |
| --- | --- | --- |
| 0:00–0:35 | Terminal and moonlit scene | “A dependency bump is easy. Knowing which lines it breaks is harder. Upgrade Oracle turns release notes and your source into a reviewable migration report.” Point out the beige 5150 frame, CRT and the recorded-run badge. |
| 0:35–1:10 | Next.js sample, file tabs | “This cartridge upgrades Next 14.2 to 16. These are real sample files: synchronous request APIs, a config and middleware. The recorded run used GLM-5.3 through Nebius; replaying it now makes no new model calls.” Show the exact versions and source. |
| 1:10–2:00 | Consult; Next.js results | “npm resolves the versions, GitHub supplies release and migration notes, and GLM extracts structured breaking changes. Deterministic matching puts exact code hits first.” Read an actual displayed finding and its suggested fix. “The labels describe lexical evidence; they do not prove execution.” |
| 2:00–2:50 | Open evidence receipt | Read the source version, original URL and verbatim quote. “A claim is discarded if the quote is not an exact substring of the fetched source for this version. This receipt connects that text to this filename and line. GLM's interpretation still needs human review.” Close with Escape. |
| 2:50–3:25 | Coverage and agent trace | “This is a bounded audit. The coverage panel exposes gaps. Every fetch and model call has its URL, elapsed time and bytes; even missing changelog files and cache hits remain visible.” Expand one source request and one model request. |
| 3:25–4:15 | React Router cartridge | Run the Router example. Show the actual v5 API findings and migration instructions. Open one receipt. “Official version-pinned migration docs fill in what a short release announcement leaves out.” |
| 4:15–4:55 | ESLint cartridge | Run ESLint 8 → 9; show the config/custom-rule file and a matched removed API or rule. Use the verdict filter, then return to all findings. Download JSON. “The complete report includes original evidence, so a teammate can review it later.” |
| 4:55–5:30 | Input tabs and operator manual | Show package-manifest comparison and public GitHub mode without submitting. “Live mode supports custom inputs, up to six dependencies, five pasted files or thirty sampled repository files. The server key stays on the server. In demo mode, editing a sample never pretends to reanalyze it.” |
| 5:30–6:05 | Terminal tests; README | Run `npm test`. Show the tests for citations, semver, limits and offline replay. Briefly show build/typecheck commands and the shared Redis configuration note. “The local limiter enforces five per IP per hour and one hundred per day. Shared Redis makes the cap work across deployed instances.” |
| 6:05–6:30 | Return to terminal; receipt visible | “GLM reads the messy human release notes. Deterministic code checks keep evidence and ranking inspectable. The result is a migration shortlist, with a receipt for every claim. Upgrade Oracle: know what breaks before it breaks.” |

If a call is rate limited, pause filming and wait or restart only the local demo server. Do not remove the badge, label replayed metrics as current, or claim an entire upgrade is safe. For a live take, load a key privately, restart the server and record the visible live badge and actual result; model latency and findings can vary.
